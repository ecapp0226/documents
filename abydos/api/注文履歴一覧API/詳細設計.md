# 注文履歴一覧API 詳細設計
## データソース
| データソース・対抗先 | テーブル名・API名 | CRUD |
| -------------------- | ----------------- | ---- |
| DynamoDB             | orders            | R    |
| DynamoDB             | order_details     | R    |


## 処理詳細
1. AuthorizationHeaderのJWTからログインチェックを実施
   1. 一致しない、期限切れの場合401エラーを返却
2. リクエストパラメータのバリデーションチェック
   1. limit: 数値、1〜100の範囲（未指定時はデフォルト10）
   2. lastOrderId: 数値（任意）
   3. バリデーションエラーの場合400エラー(API_ERR001)を返却
3. 1．からデコードしたuser_idを使い、ordersテーブルからQueryで取得
   1. パーティションキー: user_id
   2. ScanIndexForward: false（降順で取得）
   3. lastOrderIdが指定されている場合、ExclusiveStartKeyに設定する
   4. Limitにリクエストパラメータのlimit値（デフォルト10）を設定する
4. 3．で取得した結果が空の場合、レスポンス項目ordersに空の配列を設定し、7.にスキップ
5. 3.で取得した各ordersレコードのdetail_idsを展開し、order_detailsテーブルからBatchGetItemで一括取得
   1. 各ordersレコードのorder_idとdetail_ids（NS型）からキーの組み合わせ（PK=order_id, SK=detail_id）を生成する
   2. 全キーをまとめてBatchGetItemで一括取得する
   3. 取得件数が100件を超える場合は100件ずつ分割してBatchGetItemを実行する
   4. 取得結果をorder_idをキーとしてグルーピングする
6. 3．と5.で取得した結果を対応するレスポンス項目にマッピングする
   1. 3.の取得結果にLastEvaluatedKeyが存在する場合、レスポンスのlastOrderIdに設定する
   2. 3.で取得したordersの各レコードに対して以下をマッピングする

      | レスポンス項目  | マッピング元                                                                  |
      | --------------- | ----------------------------------------------------------------------------- |
      | order_id        | orders.order_id                                                               |
      | created_at      | orders.created_at                                                             |
      | total           | 対応するorder_detailsのprice * order_numの合計値                                    |
      | delivery_status | 対応するorder_detailsの全レコードのdelivery_statusが"ED"の場合"ED"、それ以外は"PR" |

   3. 5.でグルーピングしたorder_detailsの各レコードに対して以下をマッピングし、対応するorderのdetails配列に設定する
      - details配列はdetail_id昇順でソートして返却する

      | レスポンス項目 | マッピング元                      |
      | -------------- | --------------------------------- |
      | detail_id      | order_details.detail_id                 |
      | product_id     | order_details.product_id                |
      | product_name   | order_details.product_name              |
      | shop_id        | order_details.shop_id                   |
      | price          | order_details.price                     |
      | order_num      | order_details.order_num                 |
      | total          | order_details.price * order_details.order_num |
7. レスポンスの返却
