# 概要
- 特定のAPIに限らず、共通的に使用するエラーコードはこちらで発番、使用してください。
- 共通的に使用するerror_codeは```API_ERRXXX```の形で記載すること

| HttpStatus | error_code | message                 | 条件                                      | 備考 |
| ---------- | ---------- | ----------------------- | ----------------------------------------- | ---- |
| 400        | API_ERR001 | validation check error. | バリデーションエラー                      |      |
| 404        | API_ERR002 | data not found.         | 対象のパラメータ―のデータがが存在しない時 |      |
| 401        | API_ERR003 | unauthorized.           | 未ログイン時のアクセス                    |      |
| 500        | API_ERR999 | server error.           | バックエンド内で想定外のエラー発生時      |      |
