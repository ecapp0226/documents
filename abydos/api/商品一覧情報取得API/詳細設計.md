# 商品一覧情報取得API 詳細設計
## データソース
| データソース・対抗先 | テーブル名・API名 | CRUD |
| -------------------- | ----------------- | ---- |
| DynamoDB             | products          | R    |


## 処理詳細
1. リクエストパラメーターのバリデーションチェック
2. 商品データの取得
   1. クエリパラメータのロット番号を指定し、BatchGetItemで取得する
   2. DynamoDBのBatchGetItemは返却順序が不定のため、リクエストで指定されたproduct_idsの順序に並べ替える
3. レスポンスの返却
