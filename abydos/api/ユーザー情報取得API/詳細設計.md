# ユーザー情報取得API 詳細設計

## データソース

| データソース・対抗先 | テーブル名・API名 | CRUD |
| -------------------- | ----------------- | ---- |
| DynamoDB             | users             | R    |

## 処理詳細
1. 認証チェック
   1. JwtAuthenticationFilterでCookieからトークンを取得し検証する
   2. Cookieが存在しない、またはトークンが無効・期限切れの場合、401エラー(API_ERR003)を返却し、処理を終了
2. ユーザー情報の取得
   1. JWTのclaimsからuser_idを取得する
   2. user_idを指定しusersテーブルからデータを取得する
   3. 取得結果が空の場合、401エラー(API_ERR002)を返却し、処理を終了
3. レスポンスのマッピング
   1. user_id: 2.で取得したユーザーID
   2. user_name: 2.で取得したユーザー名
   3. email: 2.で取得したメールアドレス
4. レスポンスの返却
