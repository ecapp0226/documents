# サーバー起動・停止手順

## 概要
検証環境上の各ECSタスクの起動方法を解説するページです。

### 起動手順

1. AWS環境にログインする
2. ECS画面に遷移する
3. クラスターから対象のクラスター(abydos)を選択
4. 起動したいサービスを選択し、画面に遷移する
5. サービスを更新を選択
6. 必要なタスクを1に設定し、更新を押下する
   1. 必要に応じてリビジョンを前の番号に指定する
7. タスクを確認し、必要なステータスが実行中であることを確認する

### スケジューラー設定について

ECS上のサービスごとにサービスの自動スケーリングでスケジュールによるスケーリングを実施している。
下記以外の時間でも検証をしたい、起動しておきたくない場合以下の手順に従い、スケジュールされたアクションを更新する

- 9:00 ~ 19:00: 1台起動する
- 19:00 ~ 9:00: 全て停止

#### 手順

1. AWS環境にログインする
2. ECS画面に遷移する
3. クラスターから対象のクラスター(abydos)を選択
4. 起動したいサービスを選択し、画面に遷移する
5. サービスの自動スケーリングを選択
6. スケジュールされたアクションを選択
7. XXXScaleUp(Down)のチェックボックスを選択、アクション>編集を選択
8. タスクの最小数、最大数を希望する数値に設定し、スケジュールされたアクションを更新ボタンを押下する
