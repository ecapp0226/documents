# sequences テーブル設計書

## 概要
採番用カウンターテーブル。UpdateItemの ADD 操作でアトミックにインクリメントし、一意な連番IDを発行する。

## テーブル定義

| 属性名        | 型  | Key | 説明                                         |
| ------------- | --- | --- | -------------------------------------------- |
| sequence_name | S   | PK  | 採番対象の識別名（例: "order_id", "detail_id"） |
| current_value | N   | -   | 現在の採番値                                 |

## LSI

なし

## GSI

なし

## キャパシティモード
オンデマンド

## 備考
- UpdateItem の `ADD current_value :incr` でアトミックにインクリメントし、戻り値（ReturnValues=UPDATED_NEW）を採番結果として使用する
- 初回アクセス時に属性が存在しない場合、ADD は自動的に0から加算するため事前レコード作成は不要
- 採番対象の初期値を指定したい場合は、事前に current_value を設定したレコードを登録すること
