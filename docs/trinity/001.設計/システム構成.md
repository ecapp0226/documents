# システム構成


## 技術構成

| カテゴリ         | 技術            |
| ---------------- | --------------- |
| UIライブラリ     | React 19        |
| 言語             | TypeScript      |
| ビルドツール     | Vite            |
| スタイリング     | Tailwind CSS 4  |
| UIコンポーネント | Headless UI     |
| ルーティング     | React Router    |
| 状態管理         | React Context   |
| HTTP通信         | axios           |
| テスト           | Vitest          |
| ホスティング     | Cloudfront + S3 |
  
## 前提
バックエンドエンジニア担当であり、あくまでバックエンド部分の検証や設計振り返りを軸としたい。  
  
とはいえ、現職で採用されている言語やフレームワークはある程度抑えておくことで
フロントチームとの認識合わせや調整を円滑に進めやすくすることも考慮し選定を行う。

## 選定理由

### Next.jsの比較について
以下の理由からReact + Viteの構成を採用している

- アクセスパターンからSEO的な考慮をする必要がない
- 基本的にSPAの構成になることからSSRする要素が少ない
- サーバー側の言語がJavaであること

### スタイリングについて
以下の理由からTailwind CSSおよび相性の良いHeadless UIを採用

- あくまでバックエンド系の検証の用途に専念したいので、スタイルにあまり意識を割きたくない
- AIベースで入力させやすい（デザイン用のhtmlの作成含め）
- BootStrapと比較し採用率も伸びている
- Material UIとの比較の結果、ECサイトベースのためデザインをある程度幅を広げたい（管理画面の場合は検討できそう）

### 状態管理について
Reduxなどの状態管理ライブラリもあるが現状小規模開発になることが見えており、
現時点では冗長になるためあくまでReact Contextを採用
