# コーディング規約


## 命名規則

| 対象                         | 規則                    | 例                                      |
| ---------------------------- | ----------------------- | --------------------------------------- |
| コンポーネント               | PascalCase              | AddToCartButton, ProductDetailPage      |
| hooks                        | camelCase（use接頭辞）  | useAddToCart, useCart                   |
| ユーティリティ関数           | camelCase               | validateLoginForm, isProductUnavailable |
| 型/インターフェース          | PascalCase              | CartItem, ApiResult                     |
| 定数                         | UPPER_SNAKE_CASE        | CART_MAX_ITEMS, ErrorCode               |
| ファイル名（コンポーネント） | PascalCase.tsx          | AddToCartButton.tsx                     |
| ファイル名（その他）         | camelCase.ts            | apiClient.ts, productStatus.ts          |
| テストファイル               | 対象ファイル名.test.tsx | AddToCartButton.test.tsx                |


## ディレクトリ構成

| ディレクトリ                  | 役割                                    |
| ----------------------------- | --------------------------------------- |
| src/features/{機能名}/        | 機能単位で分割（auth, cart, product等） |
| features/{機能名}/components/ | 機能固有のコンポーネント                |
| features/{機能名}/routes/     | ページコンポーネント                    |
| features/{機能名}/hooks/      | 機能固有のカスタムフック                |
| features/{機能名}/utils/      | 機能固有のユーティリティ                |
| features/{機能名}/types/      | 機能固有の型定義                        |
| src/shared/components/        | 共通UIコンポーネント                    |
| src/contexts/                 | グローバル状態（React Context）         |
| src/services/                 | API通信層                               |
| src/types/                    | 共通型定義                              |
| src/layout/                   | レイアウト関連                          |


## コンポーネント設計

- 関数コンポーネント＋名前付きエクスポート（`export function`）
- Props はインラインで型定義（小さい場合）
- ページ内のSkeletonコンポーネントは同一ファイル内に定義
- barrel export（index.ts）はfeature内のcomponentsで使用


## インポート

- パスエイリアス `@/` を使用（相対パスは使わない）
- `type` キーワードで型インポートを明示（`import type { ... }`）


## 状態管理

- グローバル状態: React Context + カスタムフック（useCart等）
- ページ状態: Discriminated Union型で管理（`{ status: 'loading' } | { status: 'success'; data } | { status: 'error' }`）
- LocalStorageとの同期はContext内で完結


## API通信

- ApiClientクラスでaxiosをラップし、Result型（`ApiResult<T>`）で成否を返す
- エラーコードは定数オブジェクト（ErrorCode）で一元管理
- サービス層（xxxService.ts）でAPI呼び出しを抽象化


## テスト

- テストファイルは対象ファイルと同階層に配置（colocated）
- Vitest + jsdom環境


## Lint / TypeScript

- ESLint: recommended + typescript-eslint + react-hooks + react-refresh
- TypeScript: strict寄り設定（noUnusedLocals, noUnusedParameters有効）
