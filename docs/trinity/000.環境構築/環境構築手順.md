# 環境構築手順


## 前提条件

- Node.js
- バックエンド（abydos）が起動済みであること


## 手順

1. リポジトリをクローン
```shell
git clone https://github.com/ecapp0226/trinity.git
```

2. `npm install` で依存パッケージをインストール

```shell
npm install
```

3. `.env.local` を配置（API接続先の設定）
   ```
   VITE_USERS_API_URL=http://localhost:8080
   VITE_PRODUCTS_API_URL=http://localhost:8081
   VITE_ORDERS_API_URL=http://localhost:8082
   ```

4. `npm run dev` で開発サーバー起動

```shell
npm npm run dev
```


## スクリプト一覧

| コマンド                | 説明                        |
| ----------------------- | --------------------------- |
| `npm run dev`           | ローカル開発サーバー起動    |
| `npm run dev:remote`    | リモートAPI接続モードで起動 |
| `npm run build`         | プロダクションビルド        |
| `npm run lint`          | ESLint実行                  |
| `npm run test`          | テスト実行                  |
| `npm run test:coverage` | カバレッジ付きテスト実行    |
| `npm run preview`       | ビルド結果プレビュー        |
  

## 補足

- ViteのproxyでAPI振り分けを行うため、フロント単体ではAPI通信不可
- `dev:remote` は `--mode development` で起動し、リモート環境のAPIに接続する
